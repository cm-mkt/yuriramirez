03 · Precio

Precio de entrada con lógica de lanzamiento

EDI funciona como front-end estratégico: debe ser suficientemente accesible para facilitar entrada, pero conservar valor percibido y compromiso. La meta no es maximizar el ticket de esta primera compra; es atraer al dueño correcto, darle una experiencia real con Yuri y abrir después el camino hacia Diagnóstico y, cuando exista fit, una solución de mayor ticket.

Propuesta comercial: Precio regular $1,850 MXN · Precio lanzamiento próxima edición $1,497 MXN. Así cuidamos valor percibido, damos una razón real para actuar ahora y mantenemos EDI accesible como producto de entrada.
Guardrail: no convertir EDI en high ticket. El objetivo comercial es: compra accesible → experiencia → implementación → Need Signal cuando aplique → Diagnóstico → Route. El backend puede capturar mayor valor después.
